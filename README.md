# Piano Fundamentals Trainer Themes

这是 [Piano Fundamentals Trainer](https://github.com/Natural516/piano-fundamentals-trainer) 的独立个性化主题仓库。

主题包以 `.pftheme` 文件通过本仓库的 GitHub Releases 分发，不直接提交到 Git。安装前，Piano Fundamentals Trainer 会验证 Theme API、最低应用版本、内容完整性和 Production Ed25519 签名。

## 已发布主题

### 孤独摇滚

- 主题 ID：`natural516.bocchi`
- 主题版本：`1.0.0`
- Theme API：`1`
- 最低应用版本：`1.5.3`
- 下载：请前往本仓库的 Releases

主题包需要 Piano Fundamentals Trainer V1.5.3 或更高版本。应用可从设置页导入、验证、安装、启用、更新或删除主题包。

## 仓库边界

- Git 只保存主题说明和公开发布元数据。
- `.pftheme` 二进制只作为 GitHub Release asset 发布。
- Production 私钥、keystore、APK、日志与临时文件不进入仓库。
- 主题包不能注入代码，也不能改变应用的练习、MIDI、持久化或乐理逻辑。
